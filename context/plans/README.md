# Plans

What is proposed and not yet done: a roadmap, a redesign, a campaign idea, a change to how we work. Use
`../templates/plan.md`. Up: [the map](../README.md).

- **A plan is not how things are.** It has `status: proposal`, and nobody should read it as done.
- **When it happens:** write how things are now in the document that covers it, and mark the plan `superseded`
  by that document.
- **When it is dropped:** mark it `historical` and put the reason at the top.
- **A plan about one topic** goes in that topic's own `plans/` folder.
- No list is kept here: the file names are the index.

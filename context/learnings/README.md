# Learnings

The things a new session would otherwise get wrong or undo: lessons, preferences, corrections, useful facts,
and decisions that still hold. Up: [the map](../README.md). How to keep this list (these lines stay):

- One dated line each, newest first, with why in a few words. A decision's line links to its record.
- About 40 lines. Past that, move older lessons into the documents they belong to and take their lines out.
- A rule for how all work is done goes in the map's rules, not here.

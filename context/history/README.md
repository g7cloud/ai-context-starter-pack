# History

One record for each thing that happened and is worth knowing later: an incident or mistake, a decision and why
it was made, a launch, a migration, a review. Use `../templates/record.md`. Up: [the map](../README.md).

- **Name:** `YYYY-MM-DD-<what-happened>.md`. No list is kept here: the file names are the index.
- **A decision also gets one line in the learnings list**, linking here, so every session knows it is in force.
- **A record is not rewritten later.** A correction is a new record, or a dated note at the top.
- **A record about one topic** goes in that topic's own `history/` folder. This folder is for the project as a
  whole, and for a small project with no topics yet.
- **Lessons do not stay buried here.** If a record changes how to work, change the place that says how to work
  (a rule or routine in the map, a document, a line in learnings) and link it to the record. If the change only
  helps when a person does it in their own tool, tell them so.
